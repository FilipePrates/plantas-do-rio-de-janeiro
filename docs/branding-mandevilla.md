# Mandevilla identity

The flower-only mark was generated with the built-in imagegen tool from the
user's attached Mandevilla crassinoda photograph. White five-lobed petals,
yellow throat, and a dark green contour keep the flower readable on light and
dark browser tabs. The prior Pitcairnia concepts remain archived.

Run `node scripts/export_branding.mjs` to export platform sizes from the master.
App configuration uses these assets for a later native build. Updating the
website does not replace the icon in an already installed APK.

## Generation prompt

Design ONE polished new flower-only logo symbol for Plantas do Rio de Janeiro
based specifically on the attached PHOTO of Mandevilla crassinoda, the WHITE
flower with yellow throat. Ignore any red Pitcairnia logo visible in the other
image; it is not the subject or design reference. Reference role: the Mandevilla
photograph supplies the botanical flower shape. Make a single open white
Mandevilla flower viewed almost head-on, with exactly five broad, gently
asymmetric slightly twisted overlapping corolla lobes, softly angular rounded
tips, and a small golden yellow funnel-shaped throat. Preserve the elegant
five-lobed pinwheel character of this particular flower, not a many-petalled
daisy. White/ivory petals, restrained pale sage inner accents only to separate
overlapping petals, a neat dark forest-green contour along the OUTER flower
edge so the white flower reads on a light browser tab, and warm yellow at the
center with a tiny deep green throat detail. Flower only: no stem, leaves,
stalk, bracts, plant background, circle, backing badge, typography or text.
Clean flat vector-like graphic shapes, minimal internal detail, beautiful
organic silhouette, sufficiently bold and simple for a 16–32 px favicon and a
44 px app header. Center the flower within a square canvas with balanced narrow
margins, flower fills about 85% of frame. Actual transparent background. No drop
shadow, photorealism, texture, mockup, gradients or watermarks. One finished
emblem, not a set of variants.
