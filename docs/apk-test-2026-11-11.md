## Repetir um build solicitado no Windows

Execute `npm run android:apk:windows` neste workspace com as ferramentas locais
já instaladas. O [script de build](../scripts/build-test-apk.ps1) usa apenas o
projeto de plantas, mantém os objetos C++ em caminho curto e registra os JSON
do catálogo como entradas da tarefa de bundle. Isso evita o limite de caminho
do Windows e a reutilização indevida de um catálogo antigo quando somente JSON
foi editado. Avisos de SDK no stderr não são tratados como falha se o processo
termina com código zero. A verificação do APK ocorre antes de informar sucesso.

Após a verificação, o diretório gerado `android/app/build` desta compilação foi
removido, liberando aproximadamente 2,3 GiB. O APK, as fontes, o editor e o cache
de compilação nativa foram preservados. Dois ZIPs de instalação substituíveis
das ferramentas já instaladas também foram removidos do cache do workspace.
