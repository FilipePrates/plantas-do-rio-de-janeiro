# Árvore-do-imperador — 11/11/2026

Added one draft illustrated profile under the current Flora e Funga name
**Martiusella imperialis**, with **Chrysophyllum imperiale** preserved as a
searchable synonym. No second entry was created for the synonym. Other names
include guapeba, guapeba-preta, marmeleiro-do-mato and fruta-do-imperador.

Sources: the cached [accepted Flora record](../sources/flora/Martiusella_imperialis.json)
and [synonym record](../sources/flora/Chrysophyllum_imperiale.json), the
[Museu Nacional/UFRJ morphological account](https://www.museunacional.ufrj.br/glaziou/pagina_11.html),
and the [dated CNCFlora 2019 account](https://proflora.jbrj.gov.br/html/Chrysophyllum%20imperiale_2019.html).
The accepted-name API currently lists only `Arbusto`; this profile uses `Árvore`
according to Museu Nacional and CNCFlora, with the discrepancy recorded in
curation notes. It retains state scope.

One [CC0 photograph](https://www.inaturalist.org/photos/413138563) from
[research-grade observation 232543995](https://www.inaturalist.org/observations/232543995)
was selected after viewing the full photograph. It shows a young individual in
the forest, with a slender stem and large leaves. Caption and `wholePlant,leaf`
tags remain draft. The observation's original identification, *Chrysophyllum
imperiale*, and its acquisition evidence remain unchanged. No flower, fruit,
seed or root tags were inferred. Other CC0 records lacked research grade; the
additional CC BY candidates were unnecessary for this one-photo profile.

Added original media: 1,297,335 bytes (about 1.24 MiB), plus one small thumbnail.
All 372 previous entries, descriptions, captions, tags and gallery orders are
unchanged. The catalog now has 373 entries, 494 represented species and 600
photographs. The complete before/after audit is in
[`sources/imperiale-2026-11-11`](../sources/imperiale-2026-11-11).

`Mostrar apenas plantas com fotos` now defaults to enabled for fresh app settings
and old settings that lack that field. Explicitly saved true/false choices are
retained. The preference can still be changed in Configurações.

The editor seed and image cache are synchronized. Start it with the Windows
launcher documented in the [editor README](../../plantas-rio-content-editor/README.md).
Existing browser drafts need explicit JSON import to load a new seed; export
valuable edits first. Browser saves do not modify the app's canonical JSON;
export and use the validated app import workflow when ready.

This change does not replace the previously built APK.
